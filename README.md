# Зубной таймер

MVP Android-приложения для детского таймера чистки зубов.

## Что уже есть

- Главный экран
- Запуск чистки в одно нажатие
- Последовательный таймер по зонам
- Пауза между зонами
- Пауза/продолжение чистки
- Досрочное завершение с записью в историю
- Экран истории
- Экран настроек
- Редактирование списка зон
- Изменение времени каждой зоны
- Изменение порядка зон
- Добавление и удаление зон
- Сброс к настройкам по умолчанию

## Зоны по умолчанию

1. Жевательная поверхность — верх справа — 20 сек
2. Жевательная поверхность — верх слева — 20 сек
3. Жевательная поверхность — низ справа — 20 сек
4. Жевательная поверхность — низ слева — 20 сек
5. Внешняя боковая поверхность — верх справа — 10 сек
6. Внешняя боковая поверхность — верх слева — 10 сек
7. Внешняя боковая поверхность — низ справа — 10 сек
8. Внешняя боковая поверхность — низ слева — 10 сек
9. Передние зубы — сверху — 15 сек
10. Передние зубы — снизу — 15 сек

## Сборка

Проект собирается в GitHub Actions. После загрузки файлов в репозиторий нужно открыть вкладку Actions, дождаться завершения сборки и скачать артефакт `toothbrush-timer-debug-apk`.


## Звук и таймер (1.2.1)

В **Настройки → Пауза между зонами → Звуки пауз между зонами → Добавить аудиофайлы** задаётся общий список. Можно выбирать несколько файлов за раз, дополнять список и удалять записи. Настройка сохраняется между запусками приложения.

В начале каждого перехода выбирается **один случайный файл**. Повторы возможны. Он звучит до конца: при паузе 2 секунды и записи 3 секунды следующая зона начнётся после окончания записи. При нулевой паузе запись также звучит полностью. Если запись короче паузы, приложение ждёт оставшееся время. Без записей работает обычная пауза. Случайный звук не запускается перед первой зоной и после последней.

**Озвучка конкретной зоны начинается одновременно с её отсчётом**, включая первую зону. Таймер не ждёт окончания озвучки. Если файлов несколько, они звучат последовательно в пределах текущей зоны; при её завершении воспроизведение прекращается и начинается переход. Прежние списки файлов сохраняются.

Круг плавно заполняется в течение текущей зоны. Общий прогресс считает только время чистки, без переходов. На схеме две зубные дуги: ваша правая сторона слева на экране. Жевательная поверхность подсвечена внутри зубов, наружная — полосой у щеки. Область схемы можно выбрать в настройках зоны.

При уходе в фон таймер и звук встают на паузу. После возвращения нажмите «Продолжить». Пауза/продолжение не меняет выбранный звук перехода. При пересоздании экрана часы сохраняются; озвучка текущего этапа повторяется сначала с тем же выбором звука паузы.
